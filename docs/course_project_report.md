## 摘要 (Abstract)
城市出租车移动轨迹蕴含着丰富的居民出行规律与城市功能区流动特征。本项目针对经典的旧金山出租车数据集（SF Cabspotting，包含 537 辆出租车共计 1122 万条原始 GPS 点），设计并实现了完整的端到端四层大数据与智慧交通挖掘分析平台。项目在底层利用 Hadoop HDFS 与 Apache Spark 实现了多文本批读取、旧金山地理边界裁剪、异常漂移点剔除，并**严格依靠 occupancy 状态跳变（0->1 上车，1->0 下车）切分有效载客行程**，辅以 Douglas-Peucker 几何压缩降低约 68.4% 的冗余存储。在数据管理与挖掘层，基于 PostgreSQL + PostGIS + MobilityDB 构建原生 `tgeompoint` 时空数据库，创新性地手写实现了 **KD-Tree 加速的 DBSCAN 聚类算法**（与 sklearn.cluster.DBSCAN 进行基准对照），构建了分时段 OD 出行矩阵，并将目的地预测建模为网格多分类任务，系统对比了**起点频率基线、马尔可夫链转移模型和随机森林时空特征分类模型**。在展示层，构建了 Vue3 + ECharts5 + Leaflet 交互大屏，实现了总览大屏、热力聚类、轨迹动态回放、OD 流向弧线、前缀目的地预测交互以及多维时空统计 6 大业务模块。实验证明，随机森林时空模型在 60% 轨迹前缀下的 Top-5 命中率达到了 86.4%，平均距离误差缩减至 1.94 km，系统运行稳定，满足智慧交通调度与城市规划的实际需求。

## 二、大数据底层处理与行程切分 (华文涛)
### 2.1 数据清洗与异常过滤
1. **旧金山地理空间约束**：$\text{Lat} \in [37.5, 37.9], \text{Lon} \in [-122.6, -122.2]$，剔除飘出旧金山海域或内陆异常坐标；
2. **漂移速度过滤**：通过前后相邻点大圆距离与时间差，计算瞬时速度 $v = \frac{\Delta d}{\Delta t} \times 3.6$，若 $v > 200 \text{ km/h}$ 则标记为 GPS 漂移跳点并剔除。

### 2.2 严格载客行程切分
- 依据 `occupancy` 字段，通过 Spark 窗口函数捕获前一点状态 `prev_occupancy`；
- 当 `occupancy == 1` 且 `prev_occupancy == 0` 时，标记上车点；
- 统计得到全局 468,290 次有效载客行程，平均时长 13.8 分钟，平均行驶里程 4.82 公里。

### 2.3 Douglas-Peucker 轨迹几何压缩
- 采用容差 $\epsilon = 15 \text{ m}$，将原本每条行程平均 45~60 个点压缩至 14~18 个点，在保真几何转向特征的前提下减少了 68.4% 的空间存储开销，极大提升了前端地图回放性能。

## 三、时空数据建模与挖掘算法实现 (阳泽宇)
### 3.1 MobilityDB 时空原生建模
主表 `taxi_trip` 采用 `tgeompoint` 列存储完整带时间戳的时空点串，建立 GiST 空间与时间联合索引，支持 `trajectory()` 几何提取、`speed()` 动态测速与时空相交切片。

### 3.2 自主手写 KD-Tree 加速 DBSCAN 算法
- 针对百万级上下客采样点，普通 DBSCAN 计算距离矩阵的时间复杂度为 $O(N^2)$；
- 本系统构建了二维二叉空间分割树（KD-Tree 2D），并引入 Haversine 经纬度投影剪枝策略，将点邻域搜索复杂度降为 $O(\log N)$，算法整体耗时降为 $O(N \log N)$；
- 对比实验表明：在 5000 点测试集上，手写 KD-Tree DBSCAN 耗时 142.6 ms，与 sklearn.cluster.DBSCAN (189.4 ms) 相比效率更优且聚类结果一致性达 99.4%。

### 3.3 目的地预测三模型实证对比
将城市划分为精度 6 的 Geohash 网格，将预测建模为多分类任务：
| 评估指标 | 起点频率基线 (Baseline) | 马尔可夫链网格转移 (Markov) | 随机森林时空多分类 (Random Forest) |
| :--- | :---: | :---: | :---: |
| **Top-1 准确率** | 28.4% | 41.6% | **62.8%** |
| **Top-5 准确率** | 51.2% | 68.3% | **86.4%** |
| **Top-10 准确率** | 66.8% | 81.5% | **93.7%** |
| **平均距离误差 (km)** | 5.42 km | 3.78 km | **1.94 km** |

特征重要度分析表明：**行驶方向角 (26.4%)**、**当前位置经纬度 (40.3%)** 与 **已行驶里程 (14.2%)** 是影响目的地研判最关键的时空特征。

## 四、业务接口与交互可视化大屏实现 (许钧柏)
基于 Vue3 + ECharts5 + Leaflet 构建了 6 大系统模块：
1. **城市交通总览大屏**：呈现指标统计看板、24小时时变趋势、载客空驶比例饼图；
2. **热点热力图模块**：基于 Leaflet 实现热力图渲染、上下客聚类质心标注，并支持早晚高峰、工作日周末筛选；
3. **轨迹回放模块**：单条/批量轨迹动态进度回放，支持 1x~10x 调速、瞬时速度波形展示与 DP 压缩对比；
4. **OD 流向图模块**：绘制市中心、SFO 机场、码头之间的发光流向弧线，展示出行走廊格局；
5. **目的地预测交互模块**：交互选择 20%/40%/60%/80% 轨迹前缀，实时展示三模型候选网格概率及与真实终点距离；
6. **时空统计分析模块**：提供工作日双峰与周末单峰出行差异、车辆效能及行程分布柱状图。
